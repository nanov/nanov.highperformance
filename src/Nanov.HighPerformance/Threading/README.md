# Nanov.HighPerformance.Threading

Concurrency primitives.

- Lock-free structures (Treiber stack with packed version counter, free lists).
- Async signaling (`AsyncAutoResetEvent`-style single-waiter events).
- `[ThreadStatic]` / `ThreadLocal<T>` caching helpers and atomic/`Volatile` utilities.

Namespace: `Nanov.HighPerformance.Threading`
